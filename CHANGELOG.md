# Changelog

## 0.9.0 - 2026-10-16

- Add reusable bounded visual statistics, optional explicit CLIP/DINOv2/BLIP/OCR adapters and per-model provenance/failure receipts.
- Add the local `/v1/analysis` service and capability discovery; compose existing PixelCue VLM taggers without copying them.
- Add axis-specific profile comparisons and exact duplicate/analysis-raster evidence. Preserve unknowns and model interpretation limits.
- Preserve `/v1/keywords`, GUI, media, scan/cache and ThumbMoves contracts; add model-free synthetic regression coverage.
- Store new neural and VLM downloads under the owning project's ignored models/ folder; add an explicit pinned-checkpoint installer with hash manifests, preserving legacy paths until deliberate migration.

## 0.8.8 - 2026-10-08

- Add explicit agent capability, improvement, validation and upstream PR guidance to the README and contributor instructions.

## 0.8.6 - 2026-10-08

- Publish the reviewed local visual-keyword service with HTTP and request-scoped Socket.IO progress.

- Use the independently released ThumbMoves thumbnail-cache library.
- Keep model downloads opt-in at use time; no media or model checkpoints are included in release packages.
- Add model-free CI, tag/version and package-content validation, and a GitHub release workflow with checksums.
- Retire stale nested source and generated metadata; make thumbnail integration tests target ThumbMoves and read UTF-8 consistently.
